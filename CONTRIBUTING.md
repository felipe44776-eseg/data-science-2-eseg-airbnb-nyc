# Contribuindo

O guia completo está em [`docs/como-contribuir.md`](docs/como-contribuir.md)
(publicado em <https://felipe44776-eseg.github.io/data-science-2-eseg-airbnb-nyc/docs/como-contribuir/>).

Resumo:

1. issue com rótulo de fase do CRISP-DM → branch `fase-N/assunto` a partir de `main`;
2. `.\tasks.ps1 test` antes do push;
3. pull request com o template preenchido e revisão de outro integrante.

Invariantes do projeto: [`CLAUDE.md`](CLAUDE.md) §Invariantes.
